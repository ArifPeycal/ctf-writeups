## Solution
We were given a website that shows details about Puteri Munajjah Az-Zahraa Azhar, Malaysian Woman International Master. It shows the chessboard and PGN file. From previous CTF, there is also chall where it uses chessboard as a steganography method https://incoherency.co.uk/chess-steg/. So by doing some research, I managed to find a website that decode PGN file.
